# Petorose visual identity direction

These are proposals for client approval. They do not replace the current company logo.

## Recommendation

Use **Refined Bloom**. It preserves the current rose-in-hexagon idea while removing the raster artefacts, uneven geometry and generic tile treatment. The flower represents aroma; the regular hexagon provides a subtle chemistry reference. **Molecular Rose** is a more technical alternative for comparison.

Before production use, the selected wordmark should be converted to vector outlines after the client approves the type treatment.

## Palette

| Role | Value |
| --- | --- |
| Night | `#120E24` |
| Aubergine | `#1D1636` |
| Violet | `#4845E4` |
| Periwinkle | `#8B8DFF` |
| Orchid | `#E384EA` |
| Saffron, calls to action only | `#FFB648` |
| Lavender mist | `#F6F4FD` |

Avoid rainbow gradients. Violet and orchid carry the brand; saffron is a restrained action accent, not a decorative third colour.

## Typography

- **Fraunces 500–600** for display headlines and the proposed wordmark. It is expressive enough for fine fragrance while remaining credible and readable.
- **Inter 400–600** for body copy, navigation, forms and technical data. Use tabular numerals for CAS and FEMA values.
- Keep the pair already used by the Rose Noir design. Do not add a third font or retain Poppins.

## Usage

- Use the horizontal lockup in the site header and the stacked lockup in the footer or catalogue cover.
- Use the mark alone below 120 px wide. Drop the tagline below 160 px.
- Keep clear space around the mark equal to one quarter of its height.
- Prefer SVG. Do not put the logo in a white JPEG box or add glow, bevel, shadow or glass effects.
- Client approval is required before replacing the existing logo or changing legal/company materials.
